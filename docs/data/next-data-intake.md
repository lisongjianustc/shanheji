# 下一批疆域资料接入清单

历史样板尚缺的核心材料是有据的政权疆域。当前发布262年3条、572年4条、661年3条争议行政／主张解释多边形；610、742年仍为待配准参考图；五包完整逐年疆界均未完成，原始范围承诺继续保留。

## 可直接接入的材料

- 带明确年代及图号／页码的地图集扫描件或PDF。
- 带出处、日期、政权标识及关系类型的GeoJSON／Shapefile／GeoPackage。
- 历史GIS数据集的下载说明和使用条件。

每份材料登记：题名、作者／编者、版次、页码或图号、地图对应年代、使用条件。图中实控、设置、臣属和推定范围需分别说明；没有说明的先作为待核条目。

## 收到材料后的处理

1. 先核对具体图幅与年代、许可说明，登记来源。
2. 记录配准控制点、比例尺和误差；保留原始描绘版本。
3. 使用共享边界检查接缝、自交、岛屿和时间重叠，不能仅靠现代地形推断古代国界。
4. 逐条记录证据和复核者；完成后才进入正式图层。
5. 只有切片的年份不被扩展为全年或相邻数十年。未知年份仍显示缺口；近年参考由用户显式选择。

补充事件坐标也需要历史地名与现地的对应依据。没有依据的事件继续保留文字列表；目前没有把现代城市中心伪装成具体战场或宫殿位置。
