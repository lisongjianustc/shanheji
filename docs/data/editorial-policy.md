# 历史内容编制规范

1. 原始文件放data/raw，保存URL、下载日期和hash。不得将受限原图打包进public。
2. 每个主张单独记录材料定位、时间精度和空间精度。机构网页也可能存在错误。
3. 政权身份与名称分开；同名不得自动合并。实际控制不等于行政设置、臣属、影响或宣称。
4. 边界不在切片之间插值；只知某年不能编造确日。原图配准保留控制点、比例尺和误差说明。
5. 事件摘要独立撰写，简洁复述已核验事实。史家的原因判断放解释字段，不作为事实。
6. 缺地点事件保留列表；近似城市定位标为近似，不当作遗址精确坐标。
7. review记录实际核验者human或agent；软件测试不等于史料复核。
8. 明显错误来源列入排除清单；待核验疆域不进入正式发布。资料缺口持续可见。
