## 可采用与限制
- Natural Earth只作为现代自然地理参考，可本地再发布；不能替代古代海岸和河流。
- CHGIS V6发布页禁止再分发，暂不纳入网页资源。
- Ourednik仓库目录已实际下载检查：300年含Han Zhao、500年含Jin Empire、700年含Sui Empire。它们与基础政权年代冲突；整个系列不进入正式图层，不能用改标签掩盖几何来源问题。
- OHM有开放许可说明，但本次尚未取得支持五包完整覆盖的具体对象。WHG访问返回403，未绕过。
- Met和Columbia时间表仅作为逐条核验入口；Met早期页265年事件描述存在明显错误，Columbia唐终点标906。机构来源也需要逐条核验，不能整体导入。

## 可行性
软件可以完整实现220—907年查询、事件、并行时间带和证据展示。完整逐年疆域仍缺少可靠且可使用的几何资料；已向用户询问资料路径，继续独立开发。不得把应用功能完成称为历史样板完成。

## 复核方式
本次为agent逐页核验与目录检查，不是历史专家审定。五个包的所有疆域缺口保留在覆盖清单中，不删除任务范围。

## 同目录旧项目核查

只读检查了相邻 `HistoryMap` 的 README 和 `src/data/atlas.ts`。其 P0 边界明确声明为粗略示意（borderPrecision=1），部分直接借用现代自然地理区域；没有获得图幅级可复核边界依据，因此没有将这些面升级为V2正式疆域。旧项目未修改。其事件与地点可作为后续逐项复核候选。
