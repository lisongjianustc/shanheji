## 配准与可重复编制

参照坐标取自GeoNames `cities15000.zip` 的十个城市点子集，CC BY 4.0，见[GeoNames记录](../../data/sources/geonames/README.md)。现代城市点仅作近似配准参照，未作为古城精确坐标或政治边界。

| 图幅 | 拟合模型 | 配准点 | 不参与拟合的检查点 | 最大检查残差 |
| --- | --- | --- | --- | --- |
| 262 | EPSG:3857 + 六参数仿射 | 6 | 4 | 13.0 km |
| 572 | LCC 23°/45° + 六参数仿射 | 6 | 3 | 20.9 km |

模型是拟合方案，不能由拟合结果断言原作者投影。残差包含古今城址移动，不是全图误差上限，也不是历史疆界精度。所有像素点、独立点、输入哈希、残差和归并表在 `data/registration/` 与 `data/audits/*-intake.json`。

262提取时排除图例及原图外框；修补封闭文字孔和近邻深色边线，保留蓝色水域；剔除小于16像素的孤立块（微小岛屿不完整），共同结点与0.8像素简化保持交界一致。572手描虚线间隙及原图陆地掩膜存在近似，未赋予中性岛屿政治归属。经原图叠加查看，修正江陵西梁轮廓与北齐辽西海岸闭合，排除未显示归属的东北陆地。

```sh
.venv/bin/python scripts/data/import_three_kingdoms_262.py
.venv/bin/python scripts/data/import_china_572.py
.venv/bin/python -m unittest discover -s scripts/data/tests -v
npm run data:validate
npm run data:publish
```

导入器输出 `data/derived` 和审计记录；正式包中相应 `territories` 与输出相同。修改来源／配准需重新输出、更新相应资料包，再通过发布门。`verified`只表示来源解释与编制过程复核，审核者为agent；`spatialPrecision=disputed`保留，未经历史专家审定。

## 尚缺

五个资料包仍为不完整。西晋、东晋十六国、南北朝其他年份、隋统一前后、唐中晚期及完整邻国均需继续编制。610年西部以模糊范围表示；742年西部混用高宗期行政与约750年外缘，不能直接作为该年精确实控疆界。事件点与都城坐标仍待补核。未知年份不会插值成似是而非的完整地图。

软件、实际绘制与手机检查记录见[验收](../qa/acceptance.md)，不能用测试通过替代史实复核。

## 约610年隋朝部分范围补充

来源：[Yug / Manlleus等《China, 610》](https://commons.wikimedia.org/wiki/File:China,_610.svg)，2026-09-21固定文件，CC BY-SA 3.0。原图指向《剑桥中国史》第3卷，说明西部资料不足并用渐隐表示；原书图幅未独立核查。原图的现代国界与省界不作为隋朝边界。

本版本提取 `Sui ~610`，显式处理SVG M/L/C/Z，曲线步长不大于0.5像素，直线2像素；沿原图陆地、湖泊遮罩裁切，0.1像素保拓扑简化。只保留 `linearGradient7461` 填充与 `linearGradient8438` 描边都完全不透明的半平面交集，并限制在原1000×850画布内。**渐隐部分未补齐，裁切线不是国界。** 原轮廓边线在裁切后独立保存在 `compilation.boundaryGeometry`，地图填色和边线分别更新，人工闭合线不绘制。

参照为[10处Natural Earth湖泊子集](../../data/sources/natural-earth/README.md)，仅用于现代自然地理近似配准。LCC 23°/45°与六参数仿射是拟合模型，不能据此证明原SVG投影。湖泊在投影中的面积重心与原图对应湖泊面积重心匹配；不使用省区文字标签当作城市点。

六湖拟合、四湖独立检查：乌布苏湖5.8公里、斋桑湖47.2公里、太湖7.4公里、洪泽湖18.6公里；最大残差47.2公里。所有检查均保留，未删除误差较大的斋桑湖。底图概化与水域变化等可能影响匹配，原因未分别确定；这些数值不是全图误差上限，更不是历史疆界精度。配准像素点、哈希、拟合矩阵及残差在 `data/registration/sui-610.json` 与 `data/audits/sui-610-intake.json`。

标签为“约610年”行政参考、`spatialPrecision=disputed`、`extent=partial-source`。仅在610年级别查询显示，不外推到609／611年，也不作为确日证据。用户显式开启近年参考时，仍标注原图幅年代610年。

导入器输出派生几何与审计；正式包 `sui-early-tang/package.json` 的相同编号记录需同步后发布。源图SHA与参照子集SHA变化时拒绝导入；发布时检查独立边线有效且沿范围边缘。裁切伪边线排除、湖泊／海洋／台湾／西部排除与确日／邻年不外推均有回归检查。新增来源版本仍未补齐隋朝西部、完整周边或其他年份。
