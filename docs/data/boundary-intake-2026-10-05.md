## 配准与可重复编制

参照坐标取自GeoNames `cities15000.zip` 的十个城市点子集，CC BY 4.0，见[GeoNames记录](../../data/sources/geonames/README.md)。现代城市点仅作近似配准参照，未作为古城精确坐标或政治边界。

| 图幅 | 拟合模型 | 配准点 | 不参与拟合的检查点 | 最大检查残差 |
| --- | --- | --- | --- | --- |
| 262 | EPSG:3857 + 六参数仿射 | 6 | 4 | 13.0 km |
| 572 | LCC 23°/45° + 六参数仿射 | 6 | 3 | 20.9 km |

模型是拟合方案，不能由拟合结果断言原作者投影。残差包含古今城址移动，不是全图误差上限，也不是历史疆界精度。所有像素点、独立点、输入哈希、残差和归并表在 `data/registration/` 与 `data/audits/*-intake.json`。

262提取时排除图例及原图外框；修补封闭文字孔和近邻深色边线，保留蓝色水域；剔除小于16像素的孤立块（微小岛屿不完整），共同结点与0.8像素简化保持交界一致。572手描虚线间隙及原图陆地掩膜存在近似，未赋予中性岛屿政治归属。经原图叠加查看，修正江陵西梁轮廓与北齐辽西海岸闭合，排除未显示归属的东北陆地。

```sh
.venv/bin/python scripts/data/import_three_kingdoms_262.py
.venv/bin/python scripts/data/import_china_572.py
.venv/bin/python -m unittest discover -s scripts/data/tests -v
npm run data:validate
npm run data:publish
```

导入器输出 `data/derived` 和审计记录；正式包中相应 `territories` 与输出相同。修改来源／配准需重新输出、更新相应资料包，再通过发布门。`verified`只表示来源解释与编制过程复核，审核者为agent；`spatialPrecision=disputed`保留，未经历史专家审定。

## 尚缺

五个资料包仍为不完整。西晋、东晋十六国、南北朝其他年份、隋统一前后、唐中晚期及完整邻国均需继续编制。610年西部以模糊范围表示；742年西部混用高宗期行政与约750年外缘，不能直接作为该年精确实控疆界。事件点与都城坐标仍待补核。未知年份不会插值成似是而非的完整地图。
