# 中国历史互动地图：三国至唐末样板设计

日期：2026-10-01  
状态：设计已获用户批准；尚未开始实现或历史数据生产。  
审批记录：2026-10-01，用户原话：“草案审核通过”。

## 1. 已确认需求与设计假设

用户希望沿时间轴连续查看不同年份各政权的疆域，在当年地图上以可点击的小亮点呈现重大事件，疆域应符合历史实际。

用户已确定：先覆盖中国历史中的各政权及周边国家，未来按需要扩展全球；样板时期为三国、魏晋、五胡十六国、南北朝至隋唐。

本设计将样板操作范围设为公元220—907年。220年之前的东汉末年作为必要背景文字和关联事件，不计入首版可浏览年份。时间端点和默认学习探索定位随本设计整体获批，并非用户逐项指定。桌面网页优先，手机支持基本浏览。

完成目标：用户能够选择样板范围内任一年，理解该年的政权格局、已收录事件，以及地图资料的精度与缺口。能够选择年份，不等于该年份所有地区均已完成疆域复原。

## 2. 方案选择

| 方案 | 优点 | 局限 |
| --- | --- | --- |
| 完整时间轴＋分时期核验的数据包（推荐） | 样板覆盖用户指定的整个时期，资料可逐步补全，适合未来扩展 | 必须清楚显示未完成的地区和年份 |
| 仅提供若干代表年份地图 | 数据生产较集中 | 无法充分满足逐年探索需求 |
| 逐年自动生成或插值疆域 | 表面上连续完整 | 不能保证历史依据，不采用 |

采用第一种方案。地图系统一次建立220—907年的浏览能力；内容按时期整理、复核并逐包接入。所有包均属于本次样板范围，分包不意味着缩减为仅制作三国。

## 3. 历史组织方式

“三国”“魏晋”“十六国”“南北朝”包含重叠时段，不能作为互斥、首尾相接的朝代列表。

时间轴由以下部分组成：

- 公元年份主轴：全局唯一时间选择器。
- 历史时期导航：用于快速定位，允许范围重叠。
- 政权存续带：依当前地区与筛选展开，显示同年并存关系。
- 事件刻度：按缩放级别显示重大事件或聚合数量。

资料工作分为五个相互衔接的包，允许重叠：

| 数据包 | 内容重点 |
| --- | --- |
| 三国与西晋 | 三国并立、统一前后变化及相关周边政权 |
| 东晋与十六国 | 南北并存、北方政权更替、地方控制与过渡状态 |
| 南北朝 | 南北各政权并行演变及周边关系 |
| 隋与唐初 | 统一进程、隋唐之际并存势力与唐初格局 |
| 唐中后期至唐末 | 边疆变化、地方实际控制变化、周边国家与唐末转折 |

同一实体可跨多个包引用；不因分包重复建立政权身份。相邻包交接时需核验时间和边界的一致性。

## 4. 地理覆盖与政权分类

主视野覆盖中国历史核心活动区域，并根据当时政权、战争、迁徙和外交关系扩展到蒙古高原、东北亚、河西与西域、中亚相关地区、青藏高原及东南亚北部。地图可以自由平移，不以现代国界裁切历史政权。

周边条目候选包括高句丽、百济、新罗、倭／日本、柔然、突厥诸政权、回鹘相关政权、吐谷浑、吐蕃、渤海、南诏等；此列表用于内容规划，不表示这些政权在同一时期并存，也不表示其边界已得到核验。各包发布时附正式收录清单和未覆盖地区清单。

实体类型至少区分政权、地方割据势力、部族或联盟、行政单位。界面按历史语境标注，不能将所有条目都称为现代意义的国家。

实际控制、行政建制、臣属关系、影响范围和宣称范围分别记录。默认疆域图层采用已核验的控制范围；其他关系通过独立图层、说明或关联线展示，不自动并入宗主政权的同色领土。

## 5. 页面与视觉

地图占据主要画面。底部固定时间轴，左侧放搜索和图层工具，右侧为可收起的详情面板。

| 区域 | 内容 |
| --- | --- |
| 顶部 | 当前年份／时点、搜索、资料覆盖入口 |
| 中央 | 地形、疆域、名称、都城、事件亮点 |
| 左侧 | 地区与政权筛选、事件分类、图层控制 |
| 右侧 | 政权／事件详情、来源、相关年份和地点 |
| 底部 | 年份输入、播放、前后一年、事件跳转、并行时间带 |
| 地图角落 | 图例、比例尺、署名、当前数据说明 |

建议采用浅米色自然地形、低饱和政权色块和高对比文字。颜色跨年份保持身份连续，但不能仅以颜色表达区别。事件使用小光点和类型图标；只突出新出现或被选中的事件，提供关闭动效选项。移动端使用底部详情抽屉。

默认隐藏现代行政界线和现代城市标签。现代定位辅助层可单独开启，并明确标注为现代参考。历史河流、海岸线资料不足时需说明底图年代，不能把现代地形参考直接称为当年自然地理。

## 6. 时间交互与状态规则

### 6.1 年份浏览

支持拖动、直接输入年份、前后一年、自动播放及上一／下一重大事件。拖动时预览年份，地图加载完成后一起提交年份、疆域与事件状态，避免标题已更新而地图仍停留在旧年份。快速拖动时丢弃过期请求。

年度视图包含当年事件，并在疆域旁明确显示参考时点。资料足够时默认采用该年年末格局；当年存在已知变化时提供“变化前／变化后”节点。未精确到日的变化以年份或日期区间表达，不补造1月1日或12月31日作为史实。

疆域图层与事件列表可能表达同年不同阶段。点击事件后，只有存在与事件时点匹配的疆域状态时才切换到该状态；否则保留当前地图，并提示“当前疆域参考时点与事件时点不同”。

### 6.2 变化与缺口

- 有依据支持一个时段内状态有效：该时段使用同一条疆域记录。
- 只有单年切片：只保证该切片年份，不默认为长期有效。
- 仅有邻近年份资料：默认显示资料缺口；用户可主动打开“邻近年份参考”，并持续显示参考年份。
- 有明确变更依据：在变更节点切换，可短暂高亮发生变化的区域。
- 时间或边界存在争议：保留不同解释和来源，不自动合并为确定结论。

镜头和透明度可平滑过渡；不得通过多边形插值生成中间年份的历史边界。

### 6.3 播放与选中

点击疆域或事件即暂停播放。年份变化后，已选政权仍存在则更新其详情；不再存在则提示并提供跳至存续期入口。已选事件离开当前年份后取消地图高亮，保留返回入口。

## 7. 疆域详情

点击疆域显示政权当时名称、存续时间、都城、实体性质、当前疆域参考时点、相关事件、前后变化及依据。统治者等信息仅在已有核验数据时展示，不作为首版必填项。

边界不确定性使用虚线或范围带；关系类型使用独立图例。没有证据支持的面积、人口、兵力等数值不从地图形状或模型推测后当作事实展示。

多个来源发生冲突时，提供明确命名的来源版本。默认版本依据编制说明选择，保留不同版本入口及采用理由。

## 8. 事件互动

类型包括战争与军事行动、政权建立和终结、政治制度变化、外交交往、迁徙与民族互动、经济文化和宗教、灾害等。首版重大事件依据历史格局影响及资料可核验程度收录，保留编辑说明，不要求每年填满事件。

事件卡片包含名称、日期及精度、地点及精度、摘要、经过、关联政权与人物、来源和争议说明。叙述应区分发生事实与史家对原因、影响的解释。

- 同地点多事件：聚合显示数量，点击选择。
- 持续事件：分别标记开始、持续和结束；播放时避免每年重复弹出。
- 多地点事件：共用一个事件身份，通过不同地点记录关联。
- 大致地点：范围或近似点配合明确标记。
- 无可靠地点：进入当年列表，不强制落点。
- 键盘和触屏均可访问详情，不依赖鼠标悬停。

迁徙或战役路线只有在各阶段地点和时间得到核验后才绘制，作为后续功能。

## 9. 数据结构与来源

| 对象 | 必需信息 |
| --- | --- |
| 政权／势力 | 稳定编号、名称及有效期、实体类型、存续时段、来源 |
| 疆域状态 | 对象编号、几何范围、有效时段、时间与空间精度、关系类型、来源版本、复核状态 |
| 地点 | 稳定编号、异名及有效期、位置或范围、位置精度、来源 |
| 事件 | 编号、时间范围与精度、关联地点和政权、类型、摘要、来源、复核状态 |
| 来源 | 作者或机构、题名、版本、页码或图号、链接、获取日期、使用条件 |
| 覆盖记录 | 时段、地区、主题、已核验／待核验／缺失状态与说明 |

政权身份与名称分开，地点身份与坐标分开，来源支持的主张与展示几何分开。编号不嵌入现代国家归属，以便未来全球扩展。

精确的内部有效区间采用统一的起点包含、终点不包含规则；不确定日期单独记录最早／最晚范围和精度，不强制转成精确日。行政、臣属和继承关系必须附带有效期。

数据流程：收集来源 → 提取主张 → 配准与绘制／结构化事件 → 时间和空间校验 → 内容复核 → 发布版本。AI辅助整理不能代替史料核验；正式数据不得混入用于界面演示的虚构样例。

已查阅的资料入口：

- CHGIS：历史地名与行政单位基础资料，存在时间序列地域覆盖限制，不能直接视为逐年完整国家疆域库。https://chgis.fas.harvard.edu/pages/intro/
- World Historical Gazetteer：可参考历史地点、异名、时间精度与空间不确定性的建模。https://docs.whgazetteer.org/content/v4/user-guide/getting-started/concepts.html

这些入口不构成已完成的疆域资料库。具体下载版本、图层内容与再发布权限在采用前逐项核验。历史图集数字化记录原图版本、比例尺、配准方法、控制点和误差说明。

## 10. 技术职责划分

技术建议为React／TypeScript界面与MapLibre GL JS地图，具体版本在实现前核验。MapLibre已有时间滑块筛选示例：https://maplibre.org/maplibre-gl-js/docs/examples/create-a-time-slider/

- 时间状态模块：管理年份、具体节点、播放和选择状态。
- 历史数据查询模块：按时间、地区和资料版本返回可展示状态及覆盖说明。
- 地图模块：展示几何、标签、亮点及选择，不自行推断历史关系。
- 详情模块：展示叙述、出处和关联跳转。
- 数据构建模块：校验、生成分时期资源和发布清单。

首版采用按时期与地区加载的静态数据包，避免一次下载全部几何。数据增长后可转换为矢量瓦片并引入空间数据库，不改变政权、事件和来源编号。首版不需要账户、社区投稿或在线内容编辑后台。

## 11. 实施阶段与完成边界

1. 资料覆盖审计：检查五个包的来源、授权、时间精度和空间缺口；输出可行性与覆盖清单。
2. 产品骨架：建立220—907年时间轴、地图、并行时间带、详情和覆盖提示；测试样例明确标识。
3. 历史内容接入：依次整理五个包，发布经过核验的几何和事件；交接处检查一致性。
4. 全时段联调：验证跨包浏览、日期切换、周边政权和缺失数据表达。

样板完成条件：五个包均经过覆盖审计，已承诺收录的政权及事件完成核验接入，所有已知缺口可见；产品骨架完成或三国包完成，都不能宣称整个样板内容已完成。

不预先承诺每一年的每一条边界都可精确重建。审计发现关键时段无法支持预期展示时，应在覆盖清单中说明，并与用户确定该部分采用参考切片还是继续补充资料。

## 12. 验收重点

- 三国、东晋与北方政权、南北朝等并存关系可在同一时点正确显示。
- 220、907及各包交接节点可访问，不出现时间断档或重复身份。
- 快速拖动后，年份标题、疆域、事件与详情同步，旧请求不覆盖新结果。
- 年内变化和日期不确定性正确表达，事件与疆域时点不同会提示。
- 没有有效数据时显示缺口，未收录区域不会被误读为无人统治。
- 臣属、影响范围与实际控制不被混涂；有依据的重叠控制允许保留。
- 每个正式疆域状态和事件可追溯到具体来源；冲突版本和编制说明可查看。
- 数据检查能识别无效几何、断裂引用、倒置时间区间及异常重复；相邻几何的重叠或缝隙需审查，不能无条件自动消除。
- 各数据包首尾、主要疆域变化点和事件密集年份经过视觉核验。
- 键盘、鼠标和触屏可完成年份选择与详情查看；降低动效设置有效。
